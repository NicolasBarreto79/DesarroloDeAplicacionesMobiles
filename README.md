# Desarrollo de Aplicaciones Móviles

Repositorio de trabajos prácticos de la carrera **Licenciatura en Sistemas de Información**.

## Trabajos Prácticos

- **[TP2 - Flujo checkout tienda](./TP2%20-%20Flujo%20checkout%20tienda)**: Flujo de compra para una tienda online con navegación nativa, selección de color, talle y cantidad, eliminación de productos y selección de medios de pago en la pantalla de Secure Payment (Visa, MasterCard y Otras).
- **[TP3 - LoginiBankSupabase](./TP3%20-%20LoginiBankSupabase)**: Aplicación bancaria iBank con flujo de autenticación completo en Supabase Auth, validaciones Zod, prevención de enumeración, deep linking y persistencia segura de sesión.
- **[TP4 - AgroPulse](./TP4%20-%20AgroPulse)**: Sistema de agricultura de precisión impulsado por eventos (Event-Driven Architecture) con Supabase (PostgreSQL 17 + PostGIS + RLS), Redpanda (Kafka API), patrón Transactional Outbox y aplicación móvil en Expo SDK 57 / React Native.
